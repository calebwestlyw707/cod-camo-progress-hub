## What CAMO COD HQ Does

CAMO COD HQ is a web companion built around camouflage completion in Call of Duty. It gives players a single location for reviewing and following camouflage objectives across the franchise.

Instead of maintaining separate checklists for individual games, players can use the project as a centralized progress reference. The web experience is intended to remain useful as the supported Call of Duty camouflage content is updated.
